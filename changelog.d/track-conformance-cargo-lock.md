Tooling only. `conformance/Cargo.lock` was listed in `conformance/.gitignore`, so the PM stamp tool (`tools/stamp-at-merge.sh`, which runs `cargo metadata --locked` on `conformance/Cargo.toml`) failed with exit 101 and could not stamp any KISS PR.
