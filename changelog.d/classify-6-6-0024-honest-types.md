Draft change; no byte of any key moves and no request field is added. New clause KISS-CLASSIFY-6.6-0024 in `spec/classify.md` (sidecar `spec/sidecar/classify.json`, matrix row, test `test_classify_request_states_input_types` in `conformance/tests/classify_request_types.rs`): a consumer deriving a `structure_key` MUST state each operand's dtype, extents and strides as the operand actually is, and a provider has no obligation for a buffer that differs from what the request stated.
