**Breaking** Draft change to KISS-Classify, KISS-Ops, KISS-Contract and KISS-Announce, one re-derivation for consumers (CireSnave boards 430 Q2 "2a" and Q5 "b", 443, 444, 2026-11-13 and 2026-11-14; plan `docs/plan-sk8-batch.md`). (1) **Classify `sk7` to `sk8`:** every per-operand sub-key carries its operand's dtype as a mandatory sixth component, before the optional `dl`/`dc` (`spec/classify.md` KISS-CLASSIFY-6.6-0007, 6.6-0015 replaced, 6.7-0004); the first sub-key's dtype must equal field 2 (`PrimaryDtypeMismatch`), a reserved dtype in any operand declines, and a `ctr` `<wdt>`/`<out>`/`q<sdt>` must be a dtype some sub-key carries (`OperandDtypeDisagrees`); a quantized `ctr` cell keys the block length `g16`|`g32` after `q<sdt>` (6.6-0022a, 6.7-0006; the product of the weight's `block_shape`, closed set {16, 32}, the group axis implied and not keyed; `BadBlockLength`, `BlockLengthMissing`, `BlockLengthUnsupported`); `sk7` is re-derived, never decoded (6.7-0014). (2) **No `x<n>` escape** (KISS-CLASSIFY-6.6-0026, `spec/namespaces/vulkan.md` V-7, Vulkan vocabulary version 6): a Vulkan tuple with an unnamed component type is omitted whole, and the Announce device record gains a trailing `unnamed_types` list (KISS-ANNOUNCE-6.6-0011, `MAX_UNNAMED_TYPES` 64, `MAX_UNNAMED_ID_LEN` 256). (3) **Ops:** the `matmul` OpAttrs blob is `accumulator`, `math_fidelity`, `accuracy_kind` (none, max_ulp, max_relative, max_absolute) and a `u64` LE `accuracy_value`, eleven bytes, replacing the 0.17.0 `precision_tag` (KISS-OPS-6.19-0049, 6.17-0011: a kernel is admitted iff it declares a same-kind tier no looser than the request); a kernel advertising a reduced-mantissa cell for any op must declare a tier (KISS-OPS-6.17-0012, KISS-CONTRACT-6.8-0002 carve-out); 6.17-0006 is a measuring reference only; the float accumulator stays the requester's floor. Corpora regenerated with the `emit_*` bins: `structure_key_vectors`, `structure_key_derivation_vectors`, `contract_vectors` (the Appendix C golden is now `KISC kiss-contract 4 len=1304 crc32=2854c69d`, 1349 bytes), `dtype_manifest`, `opattrs_vectors`, `opattrs_value_vectors`, `announce_vectors`. Floor: harness 554. No Unpopped code reads or writes a non-`none` `precision_tag` (Unpopped@9be7e15e).
